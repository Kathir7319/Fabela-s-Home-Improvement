## 🏗️ Project Overview

A modern, responsive, high-performance multi-page React application built for **Fabela's Home Improvement Contractor Services LLC**. The platform showcases the company's dual specialties in residential remodeling and mobile welding fabrication with direct, transparent client communication and upfront estimates.

### Key Pages & Features
- **Home:** Architectural bento-grid hero, verified BBB credentials, 3 Core Pillars (Certified Expertise, Fully Versatile, BBB Accredited), and customer testimonials.
- **Services:** 4 trade hubs matching industry standards:
  1. *Home Remodeling & General Handyman Repairs* (Bathroom/Kitchen renovations, Drywall, Painting, Carpentry)
  2. *Custom Mobile Welding & Fabrication* (On-site gates, security fences, structural steel, aluminum repairs)
  3. *Flooring Installations* (LVP, laminate, tiling, solid hardwood)
  4. *Electrical, Plumbing & Exterior Fixtures* (Fixtures, troubleshooting, deck staining, sealing)
- **About Us:** Craftsman story behind Joseph Fabela, property care commitments, and mobile welding rig spotlight.
- **Gallery & Visual Proof:** Filterable trade portfolio and an **interactive before-and-after slider**.
- **Interactive Estimator:** Dynamic investment range & project timeline calculator with 1-click SMS dispatch.
- **Daily SMS Progress Simulator:** Real-time demonstration of Joseph's daily photo and text progress updates.
- **Triangle NC Service Area Checker:** Interactive neighborhood coverage & mobile dispatch calculator for Morrisville, Cary, Raleigh, Apex, Durham, and Chapel Hill.
- **Contact & Free Quote Modal:** Comprehensive upfront quote request form with direct SMS / Call triggers.
- **Mobile Quick Bar:** Fixed mobile dock for 1-tap phone calls, SMS texts, and instant quote requests.

## 💻 Getting Started Locally

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or pnpm

### Installation

1. **Clone the repository:**
   ```bash
   git clone <your-repo-url>
   cd "Fabela's Home Improvement"
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start local development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:5174](http://localhost:5174) in your browser.

4. **Build for production:**
   ```bash
   npm run build
   ```

5. **Preview production build:**
   ```bash
   npm run preview
   ```
